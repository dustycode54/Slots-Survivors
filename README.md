# Slots-Survivors
A slots rogue-like gambling game!

Pull the lever, score points from your rolls, and hit the quota before you run out of pulls. Survive a round and you pick an upgrade (extra rolls, double-scoring 7s, luckier symbols) to prepare for the next, harder quota. Miss it and the run is over.

There is no betting. It's just you, the machine, and a quota that keeps going up.

## Tech Stack
- **Python 3**: game logic
- **pygame**: rendering and input

The game runs locally. It also serves as a showcase of core data structures (sets, lists, dictionaries) used in real gameplay systems.
